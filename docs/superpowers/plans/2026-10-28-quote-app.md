# quote-api + quote-web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first real app in Cerberus — a Go backend (`quote-api`) returning a random quote and a React frontend (`quote-web`) displaying it — through the full dev → staging → prod ArgoCD promotion path, replacing the placeholder at `cerberoast.site`, and establish the concrete convention every future `apps/*` directory will copy.

**Architecture:** Two independently built/deployed apps (`apps/quote-api` Go, `apps/quote-web` React+TS), each with its own `Dockerfile`+`Justfile` per the repo's existing `apps/*` convention. One generic, reusable Helm chart (`infra/helm/charts/app/`) is instantiated per app per environment via ArgoCD multi-source `Application`s wired into the existing `root-apps.yaml` app-of-apps. CI runs on GitHub-hosted runners (ARC deferred to its own epic) and `deploy.yml` becomes a real, working promotion mechanism for the first time.

**Tech Stack:** Go 1.23 (`net/http`, `math/rand/v2`), React 18 + TypeScript + Vite + Vitest + React Testing Library, Helm 3, ArgoCD (multi-source `Application`s), Kustomize, GitHub Actions (`ubuntu-latest`).

**Spec:** [`docs/superpowers/specs/2026-10-28-cerberoast-first-app-design.md`](../specs/2026-10-28-cerberoast-first-app-design.md)

## Global Constraints

- No self-hosted runner pool exists yet — every workflow in this plan runs on `ubuntu-latest`, not `arc-runner-set`.
- Nexus (Epic 2) is out of scope for this plan entirely — tracked as a separate plan.
- `cerberoast` namespace, `traefik-public`, and the `letsencrypt-public` `ClusterIssuer` already exist and are reused, never duplicated.
- dev/staging: `ClusterIP` only, no public DNS/TLS, reachable at `*.svc.cluster.local` or via `kubectl port-forward`.
- prod: `quote-api`/`quote-web` deploy into the existing `cerberoast` namespace, not a new `prod` namespace.
- CORS: dev/staging allow any origin; prod locks to `https://cerberoast.site` and `https://www.cerberoast.site` only.
- The frontend never bakes its API URL into the build output — it is injected into a static `env-config.js` at container start, from an `API_URL` environment variable.
- The generic Helm chart has no `NetworkPolicy` template in v1 — Kyverno's `enforce-namespace-baseline.yaml` auto-generates default-deny for new namespaces, and `cerberoast`'s existing `allow-traefik-public-ingress` (`podSelector: {}`) already covers prod. Neither app needs egress.
- Every container must satisfy the live Kyverno baseline: `runAsNonRoot: true`, `readOnlyRootFilesystem: true`, explicit `resources.requests`/`limits` for both `cpu` and `memory`, no `:latest` tag, and (for `ghcr.io/raiseofeasv/*` images) a valid cosign signature from `build.yml`.
- `deploy.yml`'s `environment` choice must be `[staging, prod]`, not `[staging, production]` — the existing `infra/k8s/environments/` directories and `root-apps.yaml`'s `Application` names/namespaces are already `prod`, not `production`.

## Review Focus

- Empty or malformed quote list at startup — `quotes.Random` must return `""`, not panic with an index-out-of-range. (Task 1)
- Cross-origin preflight (`OPTIONS`) requests — now that the frontend and backend are on different subdomains, a browser sends a real preflight before the first `GET /quote`; a handler that only handles `GET` breaks every browser call silently. (Task 2)
- Frontend behavior when the API is unreachable or returns a non-2xx — must show a visible error state, not an infinite spinner or a blank page. (Task 5)
- Promoting the *same* built image across dev → staging → prod without a rebuild — the API URL must actually change at container start, not silently keep the previous environment's value baked in. (Task 6)
- Kyverno admission-time rejection (missing resource limits, running as root, unsigned image) — must be caught before a real sync, not discovered as a mysteriously un-synced ArgoCD `Application`. (Tasks 9, 10, via `kubectl apply --dry-run=server` against the live cluster, which runs real admission webhooks.)

- [ ] **Step 3: Implement `server.New(allowedOrigin string) http.Handler` in `server.go`**

import { getApiUrl } from "./config";

export interface QuoteResponse {
  quote: string;
}

export async function fetchQuote(): Promise<string> {
  const res = await fetch(`${getApiUrl()}/quote`);
  if (!res.ok) {
    throw new Error(`request failed: ${res.status}`);
  }
  const data = (await res.json()) as QuoteResponse;
  return data.quote;
}
